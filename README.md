وافي (Wafi) - المساعد التعليمي الذكي للتشخيص والتعلّم

وافي (Wafi) هو تطبيق تعليمي مدعوم بالذكاء الاصطناعي يُساعد الطلاب على استيعاب المناهج الدراسية وتحويل ملفات الـ PDF الجافة إلى تجربة تعلم تفاعلية تشخيصية وعلاجية باستخدام نماذج Google Gemini.

---

المميزات الرئيسية (Key Features)

- تحليل المستندات (PDF Analysis): قراءة المحتوى التعليمي وتحليله بدقة.
- التشخيص الدقيق (Knowledge Gap Diagnosis): توليد أسئلة تشخيصية لتحديد الفجوات المعرفية لدى الطالب.
- الجرعات العلاجية (Targeted Learning): تقديم شروحات مبسطة وتشبيهات واقعية لربط المفاهيم الصعبة.
- معلم افتراضي تفاعلي (AI Tutor Chat): إمكانية التحدث المباشر مع المعلم "وافي" للاستفسار عن أي نقطة غامضة.

---

التقنيات المستخدمة (Tech Stack)

- Frontend: React, Vite, Tailwind CSS
- Backend / API: Node.js, Express
- AI Engine: Google AI Studio (Gemini Models)

---

كيفية تشغيل المشروع محلياً (Getting Started)

1. تحميل ملفات المشروع:
   git clone https://github.com/TahaniAlKubra/Wafi-Ai.git
   cd Wafi-Ai

2. تثبيت المكتبات والبرامج المطلوبة:
   npm install

3. تشغيل التطبيق والمعاينة:
   npm run dev
